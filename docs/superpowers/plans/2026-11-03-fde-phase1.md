# Track FDE Phase 1: hạ tầng + module 00–03 + capstone m00–m03 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bật track `fde` trong app với lab VM "máy khách" (`fdekit.py`), sản phẩm hư cấu `quillo` v1.0/v1.1 đóng được thành bundle offline, mục Cloud lab tách riêng trong app, module 00–03 đầy đủ và capstone m00–m03 (chấm repo riêng của người học).

**Architecture:** Nội dung theo `CONTENT_SPEC.md`. Máy khách là VM QEMU/KVM dựng từ cloud image chính thức + cloud-init, chạy trên overlay qcow2 của một "golden image" theo hồ sơ khách (chuẩn bị một lần, có mạng); khi test, VM dùng mạng user-mode `restrict=on` và chỉ thấy các dịch vụ phía host (proxy TLS inspection, registry) qua `guestfwd`. Sản phẩm `quillo` nằm ở `tracks/fde/product/`, phát hành thành bundle tar (image `docker save` + model GGUF + compose + manifest sha256). Capstone làm ở repo riêng của người học, bộ chấm trỏ vào qua `FDE_CAPSTONE_DIR`.

**Tech Stack:** Python 3.12, uv, pytest; QEMU/KVM (`qemu-system-x86_64`, `qemu-img` đã có), cloud-init NoCloud (seed ISO sinh bằng **`pycdlib`**, dependency mới); OpenSSH; Docker (host) + DockerLab; mitmproxy (container) cho proxy TLS inspection; `registry:2`; sản phẩm: FastAPI + Jinja2 + htmx (vendor sẵn, không CDN), Postgres + pgvector (`pgvector/pgvector`), **llama.cpp server** (image CPU nhỏ) cho LLM và embedding, model GGUF nhỏ; Vite/React app (sửa nhỏ).

**Spec:** `docs/superpowers/specs/2026-11-03-fde-track-design.md`. Plan này phủ Phase 1 ở mục 9 của spec. Phase 2–4 có plan riêng, viết ngay khi phase trước xong.
